# Mouse Saver 

Mouse Saver is an application designed for content creators who want to keep their mouse cursor in the same position between video cuts.

##  Features

*  Save the current mouse position
*  Quickly restore the saved position
*  Useful for video recording and editing
*  Simple and lightweight

##  Supported platforms

*  **Linux** — `.deb` available
*  **Windows** — coming soon
*  **MaxOS** — coming soon

##  Installation

### Linux

Download the latest `.deb` package from the [Releases](../../releases) section.

Then install it with:

```bash
sudo apt install ./mouse-saver_1.0.2_amd64.deb
```

### Windows

Windows support is **coming soon**.

### MacOS

MacOS support is **coming soon**.

##  Usage

Launch Mouse Saver and use it to save and restore your cursor position while recording or editing videos.
