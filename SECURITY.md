# Security Policy

## Supported Versions

Mouse Saver currently provides security updates for the latest stable release.

| Version               | Supported          |
| --------------------- | ------------------ |
| Latest stable release | :white_check_mark: |
| Older releases        | :x:                |
| Development versions  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Mouse Saver, please **do not report it through a public GitHub issue**.

Instead, please report it privately using **GitHub Security Advisories** for this repository.

When reporting a vulnerability, please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* The affected Mouse Saver version
* Your operating system and version
* Relevant screenshots, logs, or other useful information

## Response

Security reports will be reviewed and investigated.

If a vulnerability is confirmed, we will work on a fix and release an updated version as soon as reasonably possible.

Please do not publicly disclose the vulnerability until a fix has been released.

Thank you for helping improve the security of Mouse Saver.
